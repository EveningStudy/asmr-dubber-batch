# ASMR-Dubber AutoFlow

[ASMR Dubber 主项目：音频识别、翻译、配音与双语字幕制作](https://github.com/EveningStudy/ASMR-Dubber)

ASMR-Dubber AutoFlow 是 [ASMR Dubber](https://github.com/EveningStudy/ASMR-Dubber) 的批处理助手。给它一个解压后的 DLsite 音声文件夹，它会找出可用音轨、让你确认版本和输出方式，然后依次完成 ASR（语音识别）、翻译、TTS（语音合成）、混音、字幕和视频输出。

它只负责整理和自动执行流程，不自带模型，也不会修改 ASMR Dubber 的代码、全局设置或原作品文件。

当前代码支持 ASMR Dubber 0.7.1 及后续兼容版本，并已按 0.7.3 验证。早期免安装包不具备这里使用的台本导入和项目级参考接口。

## 能处理什么目录

程序会递归扫描作品文件夹，不要求所有音频都堆在第一层。常见命名都能排序，例如：

```text
01 开场.wav
#2 耳语.wav
Track03 添い寝.flac
トラック４ エピローグ.mp3
04a 左耳.wav
EX01 特典.wav
```

如果作品同时带有 WAV、FLAC、MP3、SE 有/无、纯人声、左右反转或中文目录，程序会把它们分成不同版本供你选择，不会把同一内容的几个版本全混在一起。特典、样本、Free Talk 和闹钟音轨会单独提示；此时必须输入 `Y` 包含或输入 `N` 不包含，其他输入会重新询问。

同名台本或字幕会自动配对。`01.wav.vtt`、`01.srt`、`01.txt` 这类文件都可以识别：

- 日文或英文台本/字幕可以直接交给 ASMR Dubber，能省掉的 ASR 就不再重复运行。
- 有时间轴的中文字幕会保留原文识别结果，只覆盖中文列。
- 无时间轴的中文台本可以直接作为中文配音稿。
- PDF 会列入扫描结果，但不会擅自解析。

如果作品文件夹名只有 `RJ01563553`、`VJxxxxxx` 这类作品编号，时间戳文档会原样保留该编号，不会因为编号没有中文译名而中止任务。

## 程序里的选项

粘贴作品文件夹后，程序会一次显示当前作品的全部默认选项：

```text
当前默认选项（继承上一个作品，可输入编号修改）：
  1. 音频版本：WAV / 日语（共 9 轨）
  2. 附加音轨：不包含
  3. 输出类型：静态视频
  4. 视频分支：普通（原音量，无前置空档）
  5. 成品组织：合并成一部
  6. 视频画面：2.jpg（推荐）
  7. 视频字幕：内嵌，同时保留 SRT/LRC
  8. 台本/字幕：发现 2 份，默认中文；可逐份修改

直接按 Enter：确认本作品，然后输入下一个作品路径
输入 0：确认本作品，并立即开始处理全部任务
```

输入 `1` 到 `8` 可以只修改对应项目；改完会回到同一个总览，不需要把其他问题重新回答一遍。下一个作品默认沿用上一个作品的处理类型、普通/和谐分支、成品组织、特典和字幕选择。

音频版本和背景图片属于作品自身，不能生搬硬套：程序会优先寻找与上次相同的音频格式和图片相对路径，找不到时使用新作品内部评分最高的推荐项。选择黑色背景则会继续沿用黑色背景。

最后一次选择会写入程序目录下的 `.state/last-options.json`，关闭程序后再次启动也能继续沿用。删除这个文件即可恢复初始默认值。

首次运行还没有历史记录时，默认使用普通静态视频、合并输出、不包含附加音轨、推荐背景图并内嵌字幕；这些都可以在总览中修改。

第 8 项用于确认作品里已有的台本或字幕是什么语言。普通命名的 `.lrc`（例如 `01.lrc`）默认按中文处理，因为 DLsite 同捆 LRC 通常是中文翻译；带有“日文”“日本語”“ja”等明确标记的文件仍会自动标为日文。进入第 8 项后可以逐份选择：

- 中文台本/字幕：不再把它交给 DeepSeek 翻译，直接作为中文稿使用。
- 日文台本/字幕：作为原文稿，中文部分仍由翻译服务生成或补全。
- 英文台本/字幕：按英文原文处理。
- 不使用这份台本/字幕：保留音轨，但完全忽略这份文件。
- 按文件名自动判断：使用扫描器根据路径和文件名判断的语言。

这个选择只作用于当前作品；返回作品串后仍可输入作品编号再次修改。

作品串会在开始处理前显示所有已经加入的作品。直接粘贴路径可以继续添加；输入作品编号可以返回修改；输入 `D+编号` 可以删除；直接按 Enter 开始整个作品串。启动时如果发现上次有失败任务，还会显示 `F1`、`F2` 等重试项；输入 `F+编号` 可把失败任务加入当前作品串，输入 `X+编号` 并确认后可以丢弃失败记录。

下面是各项选项的具体含义。

第 3 项决定输出音频还是视频：

```text
请选择输出类型：
  1. 纯音频
  2. 静态视频
```

第 4 项决定普通或和谐视频分支：

```text
请选择视频分支：
  1. 普通模式（静态背景 + 原音量）
  2. 和谐模式（成品音量 -10 dB，视频与字幕延后 20 分钟）
```

普通视频固定为 1920×1080、5 FPS。和谐模式具体降低多少分贝、延后多少分钟，以 `settings.txt` 为准。

第 5 项决定是否拼接：

```text
请选择成品组织方式：
  1. 合并成一部
  2. 每条音轨分别输出（不拼接）
  3. 分轨输出 + 合并版
```

- `合并成一部`：先拼接选中的原音轨，再建立一个 ASMR Dubber 项目。
- `每条音轨分别输出（不拼接）`：每条音轨建立独立项目。
- `分轨输出 + 合并版`：先完成所有分轨，再直接用分轨成品生成合并版，不会把 ASR 和 TTS 重跑第二遍。

所以，“纯音频模式”本身不代表一定拼接。纯音频、普通视频和和谐视频都可以搭配这三种成品组织方式。

选择视频模式和成品组织方式后，程序会把作品文件夹里的所有图片按相对路径列出来。内部评分最高的图片排在第一位并标记为“推荐”：直接按 Enter 就使用这张图，也可以输入其他编号换图，输入 `0` 使用黑色背景。原图片不会被修改。

视频模式还会询问是否内嵌字幕：

```text
是否把字幕放进最终视频？
  无论如何都会另外保留双语版.srt 和双语版.lrc。
输入 Y 内嵌字幕，输入 N 仅保留外部字幕：
```

选择 `Y` 时，最终 MP4 带字幕；选择 `N` 时，最终 MP4 只有画面和双语音轨，不包含字幕。普通视频、和谐视频、分轨和合并版都遵守这个选择。外部 `SRT/LRC` 两种情况下都会生成。

分轨任务会先处理最长的一条音轨。你只需要选择一次统一音色参考，程序会把它固化为本作品的共用参考，后面的音轨自动复用。五分钟内没有手动选择时，继续使用 ASMR Dubber 推荐的默认参考片段。

和谐模式下，每个独立分轨视频都有自己的前置无声画面；合并版只在整部作品开头增加一次。

## 使用方法

1. 先确认 ASMR Dubber 已经安装完成，网页中的 ASR、翻译和 TTS 设置能正常使用。
2. 打开 `settings.txt`，把 `asmr_dubber_path` 改成 ASMR Dubber 所在目录。
3. 双击 `ASMR-Dubber-AutoFlow.cmd`。
4. 粘贴第一个解压后的作品文件夹路径。
5. 查看默认选项总览。输入 `1` 到 `8` 修改对应项目；不需要修改时直接按 Enter 确认并输入下一个作品路径。
6. 当前作品确认无误后输入 `0`，或者在下一个路径提示处直接按 Enter。所有作品都配置完以后，程序才开始 ASR、翻译和 TTS。
7. 网页打开后，点击“打开项目”，选择一段清晰音频并点击“设为项目音色参考”。如果还改了校对表格，也要保存表格。
8. 回到命令行等待完成。

队列按添加顺序处理。某个作品失败时，它已有的状态和成品会保留，程序会记录失败原因并继续下一个作品；队列结束时会列出失败项目。失败计划保存在程序目录的 `.state/failed-tasks.json`，下次不带文件夹参数启动时选择 `F+编号` 就能重新加入并重试，原来的输出状态仍会用于续跑。成功完成后对应记录会自动删除；不想再重试时使用 `X+编号` 丢弃。带文件夹参数的单作品调用也会写入同一份失败记录。

`.state/failed-tasks.json` 是普通 UTF-8 JSON 文件，只保存路径、选项和音轨清单，不保存 API 密钥。它可以随程序文件夹一起备份；如果确认某个失败任务不再需要，优先在启动界面用 `X+编号` 删除。

多作品队列只在双击启动、没有预先传入文件夹路径时启用。命令行直接指定一个文件夹仍然只处理这一项，方便脚本调用。

ASMR Dubber 当前保存的识别模型、翻译服务、API 密钥、配音模型和混音参数都会沿用。AutoFlow 不改全局设置；它只会在自己创建的项目里保存共用参考，并在用户原本只输出中文干声时同时保留双语混音，以便生成“双语版”。

启动脚本使用 Windows 自带的 PowerShell 5.1，不要求另外安装 PowerShell 7。

## 输出位置

默认输出到作品文件夹里的 `AutoFlow输出`：

```text
AutoFlow输出/
├─ 处理清单.json
├─ 曲目清单.txt
├─ 总时间戳.txt
├─ 分轨/
│  ├─ 001 开场/
│  │  ├─ 原声.flac 或 原声.mp4
│  │  ├─ 双语版.wav/flac 或 双语版.mp4
│  │  ├─ 双语版.srt
│  │  ├─ 双语版.lrc
│  │  └─ 时间戳.txt
│  └─ ...
└─ 合并版/
   ├─ 原声.flac 或 原声.mp4
   ├─ 双语版.flac 或 双语版.mp4
   ├─ 双语版.srt
   ├─ 双语版.lrc
   └─ 时间戳.txt
```

只选择一种组织方式时，不需要的目录不会建立。`总时间戳.txt` 按原曲目顺序计算；分轨文件本身仍各自从 `00:00` 开始。

任务状态和临时文件保存在 AutoFlow 程序目录下的 `.state` 与 `.work`。中断后再次运行同一任务会继续；整项任务成功后会清掉不再需要的 `.work` 副本。输入 `Ctrl+C` 可以取消当前命令，已经完成的成品和状态会保留。日志在 `.state/autoflow.log`。

## 设置文件

`settings.txt` 中常用的项目如下：

```text
asmr_dubber_path=..\asmr-next
output_folder_name=AutoFlow输出
default_output_layout=ask
preferred_audio_formats=wav,flac,ape,m4a,mp3
bonus_policy=ask
background_policy=ask
harmonized_volume_reduction_db=10
harmonized_delay_minutes=20
```

- `default_output_layout`：`ask`、`merged`、`separate` 或 `both`。
- `bonus_policy`：`ask`、`include` 或 `exclude`。
- `background_policy`：`ask` 列出全部图片，直接回车使用内部评分最高的推荐图；`auto` 不询问并直接使用推荐图；`black` 始终使用黑色。
- `timestamp_footer_line_1` 至 `timestamp_footer_line_5`：写入时间戳文档末尾，留空即可删除。

这些设置提供首次运行的基础默认值；交互队列之后会优先沿用 `.state/last-options.json` 中最后使用的选项。已经开始的任务会继续使用创建时保存的音量、延后时间和参考音频；需要全部重做时使用 `--rebuild`。

## 命令行

```powershell
# 默认智能扫描，运行时询问模式和布局
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹"

# 纯音频，分轨和合并都输出
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --mode audio --layout both

# 普通静态视频，只输出分轨，并内嵌字幕
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --mode video-normal --layout separate --embed-subtitles yes

# 和谐静态视频，只输出合并版，不内嵌字幕
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --mode video-harmonized --layout merged --embed-subtitles no

# 指定扫描列表里的版本并包含特典
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --edition 2 --include-bonus

# 非交互指定背景：可以填写图片编号、作品目录中的相对路径、auto 或 black
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --mode video-normal --background 3
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --mode video-normal --background "おまけ\イラスト\1.jpg"

# 丢弃这一计划的 AutoFlow 成品和状态后重做
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --rebuild

# 旧版兼容：只读取根目录中数字开头的音轨，并把成品写回原目录
ASMR-Dubber-AutoFlow.cmd "D:\作品文件夹" --scan legacy

# 几秒钟的离线媒体自检，不运行 ASR/TTS，不访问网络
ASMR-Dubber-AutoFlow.cmd --self-test
```

`--embed-subtitles yes|no` 可以非交互指定视频字幕方式。视频背景保持原图比例并补黑边，不会把图片拉伸，也不会为了静态画面生成高码率视频。选择内嵌字幕时，双语视频优先烧录可见字幕；如果本机 FFmpeg 缺少字幕渲染能力，会退回到可选择的内嵌字幕轨。音频统一为 48 kHz 双声道；中间拼接使用无损 FLAC，视频音频使用 AAC 256 kbps。
